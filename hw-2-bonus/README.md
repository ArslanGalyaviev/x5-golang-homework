# Starter СР-2

Реализуйте TODO в пакетах `service` и `repository`. Публичные имена и сигнатуры
менять нельзя: их использует преподавательский набор тестов.

```bash
go test ./...
go test -cover ./...
gofmt -w .
```

Перед сдачей опишите в этом README направление зависимостей между пакетами и
приведите итоговый процент покрытия бизнес-логики.


## Направление зависимостей

repository -> service -> model

Пакет model содержит структуру заказа и не зависит
от других пакетов проекта.

Пакет service содержит бизнес-логику расчёта стоимости
доставки и использует пакет model.

Пакет repository хранит тарифы и реализует интерфейс
TariffRepository, объявленный в service.

Пакет service работает с репозиторием через интерфейс
и не зависит от его конкретной реализации.
