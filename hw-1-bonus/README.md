## Описание алгоритма

Сначала создаём отчёт и две map для хранения выручки по категориям
и количества проданных единиц по товарам.

Проходим по всем продажам. Отменённые продажи пропускаем,
а некорректные учитываем в InvalidSales.

Для каждой корректной продажи считаем выручку, обновляем общее
количество проданных товаров и данные в map.

Затем находим товар с максимальным количеством проданных единиц.
Если количество одинаковое, выбираем товар по алфавиту.

## Сложность алгоритма

- Временная сложность — O(n), так как проходим по продажам, а затем по уникальным товарам.
- Пространственная сложность — O(n) в худшем случае, так как используем две map для хранения данных.
